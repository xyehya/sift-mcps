# Archived tooling

This directory holds historical operator, migration, and proof helpers that
are not part of the supported runtime, installer, or CI surface. They are kept
for traceability only. Do not run them against a current SIFT deployment without
first reconciling their assumptions with the active installer and security model.

- `legacy-operator-tools/` contains historical VM and MCP proof helpers.
- `legacy-docs-tools/` contains validators for retired documentation contracts.
